# The Gridfather

*A margin you can't refuse.*

The Gridfather is a Windows desktop app that teaches modern CSS the visual way.
Every technique is a card: a short, plain explanation, a live demo you can see and
play with, and the code ready to copy into your project.

## Learn by seeing

- Each technique shows what it does before it shows how: a live preview, not a screenshot
- Short explanations in plain words, one idea at a time
- Chapters that go from the basics to the newest CSS: layout with Grid and Flexbox,
  fluid typography, colors and themes, animations, selectors, forms and accessibility,
  visual effects, components without JavaScript

## Code ready to copy

- One click copies the CSS (and the HTML when it needs some)
- Every snippet says whether it is safe to use today in all browsers, and gives a
  fallback when it is not
- Search across all techniques by name, property or problem ("center a div",
  "cards same height", "dark mode")

## Install

Download `TheGridfather_Setup.exe` from the [latest release](../../releases/latest) and run it.
The Gridfather updates itself from this page: when a new version is out, the app offers
it with one click.

The app is in Italian. Windows 10/11 only. Public releases only — the source code is private.
